# 第六章 学术诚信与红线

2026 年 5 月，受教育部学位管理与研究生教育司委托，中国学位与研究生教育学会发布《规范研究生学位论文与实践成果中人工智能工具使用指南》，确立了三条原则。本科生写课程论文、毕业设计同样应参照这套标准。

## 6.1 三条原则

- **诚信使用**：如实披露 AI 参与情况，支持对生成内容的事实核查。
- **科学使用**：鼓励探索创新性应用，但不得因过度依赖而弱化独立思考。
- **安全使用**：注重数据、隐私与知识产权保护，涉密与敏感内容不得用 AI 处理。

## 6.2 边界清单

| 可以交给 AI | 必须自己完成 |
| --- | --- |
| 整理资料、归纳脉络、润色表达 | 提出核心论点与创新点 |
| 检查语法、统一格式、生成参考文献格式 | 设计研究方案、判断结论 |
| 写分析代码、画图表、做排版 | 采集与核实原始数据 |
| 模拟答辩、提示可能被追问的问题 | 答辩现场独立完成陈述与问答 |

> 核心要求：谁使用、谁负责，署名者对自己提交的每一个字负责；核心论点与创新贡献必须由本人提出并完成。

## 6.3 AI 使用声明模板

```text
人工智能使用声明
本人声明，在本文（作品）完成过程中使用了如下人工智能工具：
1. 工具名称：XXX（版本号 / 官方网址）
   使用环节：文献整理 / 语言润色 / 代码生成 / 图表制作
   具体用途：……
   参数设置与验证过程：……
2. ……
本人已对上述工具生成的内容进行逐项审查、核实与修改，
核心观点、研究设计、数据与分析结论均由本人独立完成，
对本文全部内容承担责任。
声明人：          日期：
```

不同学院、课程要求不同，提交前务必确认本院系的细则。

## 6.4 幻觉核验三步法

- **要出处**：提示词里写明「给出可核查的来源（作者、年份、期刊 / 数据库）」。
- **回库查**：到图书馆数据库或搜索引擎按出处逐条核对，查不到的默认为不存在。
- **看原文**：关键结论必须打开原文确认，不看摘要就引用是学术事故高发动作。

## 6.5 数据与隐私红线

- 涉密、敏感、未公开数据（课题组原始数据、未发表成果、试卷、个人信息）不上传公共 AI 平台。
- 引用他人观点、图片、代码注明出处；AI 生成的图片与文字同样要标注来源与生成方式。
- 遵守《生成式人工智能服务管理暂行办法》《人工智能生成合成内容标识办法》等规定。
