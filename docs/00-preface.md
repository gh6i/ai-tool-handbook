# 写在前面：这本手册怎么用

| 项目 | 说明 |
| --- | --- |
| 目标读者 | 用过一两次 AI、但还停留在「问一句答一句」阶段的华农在校生 |
| 前置知识 | 会用浏览器和微信，不需要编程基础，不需要懂模型原理 |

- 本手册里的工具名称、免费额度、模型版本以 2026 年 10 月为准，AI 产品迭代极快，遇到界面变化以官方说明为准。
- 凡涉及成绩、学分、论文、经费、涉密数据的操作，AI 的输出只是草稿，最终责任在你自己。
- 手册中标有「⚠️」的地方是踩坑高发区，建议多停三秒。
