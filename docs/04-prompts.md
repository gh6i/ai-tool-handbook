# 第四章 提示词：把 AI 从「能聊」变成「能用」

## 4.1 万能公式

一条好提示词 = **角色 + 任务 + 背景 + 要求 + 输出格式**。缺哪一块，AI 就用「猜」来补，猜错的概率很高。

```text
你是[角色]，请完成[任务]。
背景：[我是谁、这门课 / 这个任务的要求、已有材料]
要求：[字数、语气、必须包含 / 必须避免的内容]
输出格式：[分点 / 表格 / 代码 / 带出处]
```

## 4.2 五个能直接复制的模板

**① 课程笔记整理**

```text
你是[课程名]课程的助教。我把一段课堂笔记粘贴在下面，请：
1. 提炼成不超过 10 条要点，每条一句话；
2. 标出我可能记错或存疑的概念；
3. 出 5 道用于自测的选择题并给答案。
笔记："""  """
```

**② 文献速读（防幻觉写法）**

```text
请阅读我上传的这篇论文，输出：研究问题、方法、核心结论、三个局限。
要求：只使用论文中出现的信息，不确定的地方写「文中未提及」，
不要补充外部知识。
```

**③ 英文润色**

```text
你是农学领域的英文学术写作编辑。请润色以下段落，
使其符合 SCI 期刊表达习惯。
要求：保留我的原意与数据；改动处用批注说明原因；
最后列出你修改的 5 处最关键表达。
```

**④ 代码调试**

```text
环境：Python 3.11，pandas 2.x。
下面是我的代码和报错信息。请：指出错误原因 →
给出修改后的完整代码 → 说明如何避免同类问题。
不要重写无关部分。
```

**⑤ 复习出题**

```text
围绕[章节]出 10 道题：6 道选择（含解析）、
2 道简答（含评分要点）、2 道综合应用。
难度对齐期末考试，不要超出教学大纲范围。
```

## 4.3 迭代三招

- **追问**：「第二点展开讲讲」「换个更简单的说法」「给一个反例」。
- **给范例**：贴一段你满意或老师表扬过的文字，说「照这个风格重写」。
- **让它反问你**：结尾加一句「如果你还需要信息才能答准，请先向我提问」，能显著减少瞎编。

## 4.4 四个常见错误

| 错误 | 表现 | 改法 |
| --- | --- | --- |
| 只给任务不给角色 | 输出泛泛而谈 | 补一句「你是……」 |
| 不设边界 | 长篇大论、跑题 | 限定字数、范围、格式 |
| 一次问太多 | 每件事都答得浅 | 拆成多轮 |
| 盲信结果 | 引用了不存在的文献 | 要出处，并回到数据库核对 |
