# 第七章 常见坑与 FAQ

| 问题 | 解答 |
| --- | --- |
| AI 给的答案和教材冲突，信谁？ | 信教材和教师讲授。AI 的优势在整理与启发，不在权威判定。 |
| 为什么同样的问题，两次回答不一样？ | 模型有随机性，重要结论请多轮交叉验证。 |
| 可以直接交 AI 写的作业吗？ | 除非课程明确允许，否则属于代写风险区；可用来打草稿、改表达，最终稿必须体现自己的思考。 |
| 免费额度够用吗？ | 日常学习基本够；重度使用再考虑订阅，先算清使用频率。 |
| 英文文献读不懂，能直接让 AI 翻译全文吗？ | 可以，但专业术语要对照原文核对，建议让 AI 输出「术语对照表」。 |
| 用 AI 写代码算抄袭吗？ | 课程作业另有规定时从其规定；科研中应如实披露，并自行验证代码正确性。 |
| 手机能跑得动吗？ | 主流工具都有网页版和 App，配置要求低；算力在云端，不依赖本机。 |
